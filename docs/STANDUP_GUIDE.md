# Daily Standup — Guía del Equipo

## Formato

**¿Cuándo?** Todos los días hábiles, **10:00 AM**
**¿Dónde?** Canal de Discord / WhatsApp / Llamada — el que usen
**¿Duración?** 15 min exactos. No más.

## Las 3 preguntas (una por persona, sin rodeos)

1. **¿Qué hice ayer que ayuda al equipo a llegar al MVP?**
2. **¿Qué voy a hacer hoy?**
3. **¿Hay algo bloqueándome?**

## Reglas

- Llega a tiempo. Si vas a faltar, avisá el día anterior.
- No te extiendas. Si necesitás más tiempo para un tema, agendalo después con quien corresponda.
- Si decís "no tengo bloqueos" pero llevás 3 sprints sin entregar, **no es cierto**. El standup es para pedir ayuda.
- Lara modera: corta si alguien se va por las ramas.

## Bloqueos comunes (y a quién escalar)

| Bloqueo | Acción |
|---------|--------|
| No puedo correr el backend local | Pedirle a Tobias que ayude post-standup |
| No entiendo un endpoint / respuesta de API | Lo mismo |
| No tengo acceso a algo | Decirlo hoy — no esperar |
| No sé por dónde empezar una tarea | Decirlo — se asigna pairing |
| Mi código no compila / da error | Pedir review rápido a otro compañero |

## Si no llegaste a tu tarea del día anterior

No pasa nada. Decilo. El objetivo es **destaparlo temprano**, no esconderlo. Si te quedaste pegado 3 horas en algo y no pediste ayuda, esa es la lección.

## Recordatorio

> "Una daily no es un reporte de status para Lara. Es una reunión para que **entre todos** destrabemos lo que sea necesario y lleguemos al MVP."
